ascii-tabs

A zero-dependency web component to write and show guitar tabs as plain ASCII. Every section shows a feature off and on, with its HTML underneath. See the spec, the glossary and the ADRs.

Editable vs read-only

Bare <ascii-tabs> is editable. readonly shows only copy on each Sheet.

Spacing

Spacing is the number of dashes between two Columns' Frets (1–6, default 2). It changes both what is shown and what is copied. The slider is a part, so it is never there unless you add it, and it works in readonly too.
